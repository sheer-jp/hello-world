# hello-world ランディングページ

このリポジトリには日本企業向けのランディングページが含まれています。ブラウザでプレビューする方法は以下の通りです。

## プレビュー方法

1. Python がインストールされている環境でリポジトリ直下に移動します。
2. 開発用サーバーを起動します。
   ```bash
   python -m http.server 8000
   ```
3. ブラウザで `http://localhost:8000/index.html` にアクセスします。
4. 停止する際は、サーバーを起動したターミナルで `Ctrl + C` を押してください。

## ファイル構成
- `index.html`: ランディングページ本体
- `styles.css`: スタイルシート
